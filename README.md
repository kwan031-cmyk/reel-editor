# 숏폼 뚝띩

설치 없이 브라우저(PC·폰)에서 쓰는 릴스·쇼츠(9:16)와 유튜브(16:9) 영상 편집기예요. 영상은 서버로 올라가지 않고 내 기기 안에서만 처리돼요.
